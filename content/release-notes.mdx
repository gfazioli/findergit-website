# Release Notes

Below is an overview of the latest changes and improvements made to FinderGit. The release notes come straight from GitHub and refresh with every release — no manual edits needed.

<MascotNote side="right" pointing label="Tip">

**In the app too:** after every update a small card says which version arrived, and **Help → Release Notes…** keeps every release one click away.

</MascotNote>

In the app, **Help → Release Notes…** (the same menu also links the **Terms of Use** and the **Privacy Policy**) opens a window with every release FinderGit carries, newest first; **Learn More…** on the card after an update opens it on the release that just arrived. Each row previews the first change of its release, the version you are running carries an **Installed** pill, and a dot marks a release you have not read yet, until you select it. When FinderGit runs in a language other than English, releases from before the app was translated carry an **English only** pill. <Kbd>⌘</Kbd> <Kbd>[</Kbd> and <Kbd>⌘</Kbd> <Kbd>]</Kbd> go back and forward through the releases you looked at, as in System Settings, and every release ends with a link to this page.
