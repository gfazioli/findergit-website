# Clone Repositories

The **Clone Repositories** window lists every repository your GitHub account can reach, or the ones you starred, and lets you clone any number of them at once into a folder you choose — no copy-pasting URLs, no cloning one at a time.

## Opening it

Cloning is an action, not a place you live in, so it opens in its own window — reachable three ways:

- **File → Clone Repositories…** (`⌘⇧K`)
- The **Clone from GitHub…** button on the [Overview](/docs/overview) dashboard
- The same **Clone from GitHub…** button on the [Account](/docs/account) dashboard

It uses the same GitHub access as the rest of FinderGit — see [GitHub Integration](/docs/github-integration) for setup. If neither the GitHub CLI nor a token is configured, the window shows a **Connect to GitHub** prompt with a shortcut to Settings.

## Your repositories, or the ones you starred

The switch at the top of the window picks the list:

- **My Repositories** — everything you can reach: repositories you **own**, ones you **collaborate** on, and ones from your **organizations**.
- **Starred** — the repositories you starred on GitHub, whoever owns them, newest star first.

FinderGit remembers the choice, and each list keeps its own sort. GitHub hands over at most 2,000 repositories per list; past that, the window says some may be missing.

## Finding the repositories you want

- **Search** by name, owner, or description.
- **Owner** — narrow to a single account or organization.
- **Type** — Sources, Forks, Private, Public, Archived, or **Not on This Mac**.
- **Sort** — by Updated, Name, or Stars; the Starred list also sorts by the date you starred each one.

Each row shows the repository name, a one-line description, its primary language, stargazer count, and when it was last updated, plus small badges for **private**, **fork**, and **archived** repos. The counter in the top-right (e.g. *39 of 368*) tells you how many match the current filter.

A repository that is **already on this Mac** — anywhere in your [Root Folders](/docs/file-browser), whatever its folder is called — shows a drive icon instead of a checkbox and can't be picked again; hover the icon to see where it is. FinderGit matches on the checkout's GitHub remote, so a folder you renamed or moved still counts.

The arrow at the end of each row opens the repository on GitHub. Right-click a row for **Open on GitHub**, and on a repository you already have, **Reveal in Finder**.

## Selecting and cloning

1. **Click a row** to select it; click again to deselect. The checkmark on the left shows what's picked. **Select All** grabs everything currently filtered, and your selection sticks even as you change filters.
2. **Choose a destination** — click the folder button at the bottom to pick where the clones land. You can make a new folder right there with **New Folder**, and the choice is remembered for next time.
3. **Pick a transport** — **Auto** reuses however FinderGit is already signed in to GitHub (see [GitHub Integration](/docs/github-integration)), so private repos clone with nothing extra to set up; choose **SSH** to clone with your own SSH keys instead.
4. Click **Clone N Repositories**. FinderGit confirms the destination first — spelling out the full path, so a forgotten or default folder can't catch you out — then starts.

Each repository clones into its own folder inside the destination, a few at a time, with a live status beside it: a spinner, then a green check or a red ✗ (hover for the error). You can **close the window while it's working** — reopen it and the run is still in progress.

When at least one clone succeeds, the destination is added to your [Root Folders](/docs/file-browser) (or rescanned if it's already one), so the fresh checkouts appear in the file browser right away.

## Notes

- Cloning a few repositories at a time keeps a large selection from flooding the network.
- A repository whose folder already exists in the destination is never overwritten: it gets a red ✗ that says so, and the rest of the batch carries on.
- For one-off clones you can keep using `git clone` or your favourite tool — this window is for pulling down many repositories in a single pass.
