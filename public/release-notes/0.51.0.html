FinderGit 0.51.0

Release notes

FinderGit 0.51.0 — Fix All, and the hooks and servers that can't start

Highlights

  • Fix All. Beside Copy Findings on Agents: every fix that needs no choosing, in one preview, each with the file it changes and every line it writes. Apply makes them one after another, each whole or not at all; one that can no longer be made leaves the others made, and FinderGit says which were not and why.
  • Hooks and servers that can't start. Agents now checks the hooks, the status line, the helpers your settings run and the MCP servers in a .mcp.json: a program that isn't there or can't run, a path with a space left unquoted, a variable nothing fills in where no shell runs. Quoting the path, making a script runnable and writing the variable the way Claude Code fills it in are fixes it makes itself, offered only when the program would then start.
  • The skill listing and the memory index. Each place's skills and commands are checked against the room Claude Code gives their listing, sized by the model that place's settings name, and a memory index nearing the part that loads is a suggestion before it becomes a warning.
  • Fewer false findings. Rules in a workspace of ignored repositories, paths into what git ignores, placeholders and generated blocks no longer raise one. The prompt handed to Claude Code or Codex asks it to write in the language each file is already written in.

Under the hood

  • The Agents dashboard is built from AgentsKit 0.8.0, shared with Lancetta, which shipped the same changes in 0.53.0.

Install

  1. Download FinderGit-0.51.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
