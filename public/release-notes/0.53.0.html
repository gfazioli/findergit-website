Release notes

FinderGit 0.53.0 — Your stars, and your card on your GitHub profile

Highlights

  • Stars over the years. A new Stars panel on a GitHub repository's Overview and on your Profile Card: every star since the first, with the stars of the last 30 days, of the last year and of the best week. Draw them as steps, the running total exactly; as a smooth line; or as bars of each month's new stars.
  • Your Profile Card on your GitHub profile. The new glancecard window writes everything that keeps the card in your profile's README, redrawn every day: the workflow, the README lines, and a one-paste prompt that sets it all up with Claude Code or Codex. Your account, your most starred repositories and the look are already filled in, and a preview shows the card as it will look.
  • A card for any repository. Open the window from the link at the bottom of the Profile Card window, or from Export ▸ Put It in Your README with glancecard… on a repository's Overview to give that repository a card of its own. A private repository can have one too: the window and the prompt walk you through the token it needs.

Under the hood

  • The star history is read from GitHub's stargazer history, thirty weeks a page, and kept on your Mac: reused for a day while the count holds, then only the newest page is read while the weeks already kept still add up. It is a port of glancecard's own reader, so the app and the action draw the same numbers.
  • The editor is glancecard's own setup, with what the app knows filled in. The workflow pins the newest glancecard release, and a private repository's card is read with a token saved as a repository secret, never handed to the app.
  • The editor's choices fall back to radio buttons, and its rows to the label above the control, when a translation is too long for the column; a test measures them in every language, with room left for a classic scroll bar.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.53.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
