FinderGit 0.19.0

Release notes

Your whole repo portfolio, at a glance — 0.19.0 adds the Repository List: every repository you track in one flat, sortable table, sliced by status and remote host.

Highlights

  • Repository List — a new flat, sortable table of every repository you track (branch · status · ahead/behind · files · size). It's the new home view.
  • Smart Views & Filters — slice the list from the sidebar by live Git status (Changes, Ahead, Behind, Dirty, Clean, each with a running count) or by remote host (GitHub, GitLab, Bitbucket, Local Only).
  • Favorites & Recents — star your go-to repositories and jump back to the ones you opened most recently.
  • Summary bar — a live tally of the whole workspace (repositories, clean, dirty, ahead, behind, total size) along the bottom.
  • Fully localized — the entire new interface follows your Mac's language in English, Italian, French, German, and Spanish.

Under the hood

  • The list reuses the existing status watchers; new lazy stores back the file-count column and the provider filters, with a bounded prefetch so large workspaces stay responsive.
  • Selecting a repository still opens the familiar 8-tab detail; double-click drills into the Finder-style file browser.

Install

Download the DMG below, drag FinderGit to your Applications folder, and launch it. Signed with Apple Developer ID and notarized by Apple — no Gatekeeper bypass needed. Existing users update automatically.

Requirements

  • macOS 15 (Sequoia) or later
  • git — provided by the Xcode Command Line Tools
