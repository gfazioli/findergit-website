Release notes

FinderGit 0.54.0 — Agents cleans up after your coding agents

Highlights

  • A Storage card on Agents. It finds what your coding agents, and the tools they run, leave on disk that nothing uses any more: Codex installs that stopped halfway, superseded Codex server releases, unfinished marketplace updates and empty git folders, files the ChatGPT app copied out, the Xcode build caches of ended sessions, and Chrome's code-sign clones. Each row says what it frees and why it can go; nothing a running program holds is offered, and each folder is looked at again just before it moves to the Trash, where the Finder can put it back.
  • Listing Choices for a crowded skill listing. A skill listing past its budget offers choices: turn off the synced skills or a plugin, or list skills by name only, each shown in full before anything is written.
  • Read the way Claude Code reads it. A settings file Claude Code drops without a word (a comment, a trailing comma, the wrong encoding) now gets a warning that says why. Your organization's policy is read as Claude Code reads it, from a managed profile too: a policy file that would stop Claude Code from starting is flagged under a badge of its own, Organization, and hooks and servers that the settings or the policy switch off are no longer flagged.

Bug fixes

  • Launch Weight counts imports and the rules of the folders above, as Claude Code's own startup warning does, so its figure matches that warning; an import from outside a project counts only where you allowed external imports.
  • Every card and row on Agents opens from the keyboard and VoiceOver too.
  • A fix never writes outside the repository on disk.

Under the hood

  • The Agents page comes from AgentsKit 0.9.9 → 0.13.0, shared with Lancetta.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.54.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
