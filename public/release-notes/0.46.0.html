FinderGit 0.46.0

Release notes

FinderGit 0.46.0 — Take the Overview with you

Highlights

  • Export the Overview. A new Export menu beside Open on GitHub saves a repository's Overview as a PNG or a PDF, or copies it as an image to paste anywhere. The picture is the whole dashboard at full height and two columns wide, whatever the size of the window, with the repository's name, its branch and the date on top, in the app's light or dark appearance.
  • Refresh follows the pull. In the Issues, Pull Requests and Release tabs, Refresh — and the scan buttons in Trust and Maintenance — now turns off and shows its own spinner while you pull the panel down to refresh it, and while the tab is loading. No more spinner above the content next to a button that still looks ready.

Bug fixes

  • English plurals. Several counts read wrong in English, because the automatic grammar agreement takes "commit" for a verb: "1 commits", "3 local commit", "3 linked worktree", "3 of these has a releases". Every count now carries its own English singular and plural, including the diverged tooltip on the branch badge, which showed its formatting code instead of a sentence.
  • The Release tab's Refresh now waits for everything its refresh waits for (the tag list and the check against the remote, not only the releases), and Trust's Scan again can no longer be clicked a second time while a scan runs.

Under the hood

  • The export draws a copy of the dashboard in an off-screen window, with Liquid Glass off (its vibrant pass does not survive a snapshot) and every entrance at rest, and measures it there. The PDF holds the same bitmap, lossless: both vector routes (dataWithPDF and ImageRenderer) were tried and drew an empty page or solid discs where the glows are.
  • The test suite no longer runs the app's own session: hosted tests used to open the saved landing and fetch the developer's own repositories at launch. Fixture git now runs off the main actor, and the app tests take about 20 seconds instead of 65.

Install

  1. Download FinderGit-0.46.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
