FinderGit 0.20.0 — Avatars, badges, and a clearer commit history

Highlights

👤 Author avatars in the Commits tab

Every commit now leads with its author's avatar, so you can scan who did what at a glance — just like the Issues and Pull Requests tabs. The avatar is resolved from the author's GitHub account, with a graceful fallback to a coloured monogram of their initials when there's no photo.

🏷️ Tag & branch badges

Commits that a tag or branch points at now wear a badge, Tower-style: tags in gold, the current branch in the accent colour, and other branches and remote-tracking refs (origin/main, …) in grey. Spotting your releases and branch tips in the history is now instant.

🌍 Localized commit dates

Relative commit dates now follow the app's language — “3 weeks ago” becomes “3 settimane fa”, “il y a 3 semaines”, “vor 3 Wochen”, “hace 3 semanas”.

⚙️ New “Detail View” settings section

A dedicated Detail View section in Settings gathers the commit-history count (how many commits the tab lists) alongside new toggles to show or hide the author avatars and the tag/branch badges — your call.

All the new interface text is fully localized in Italian, French, German, and Spanish.

Under the hood

  • Commit refs are parsed from git log --decorate=full, so tags, local branches (even slashy ones like feature/foo), remote-tracking refs, and the currently checked-out branch are each classified precisely from their full refs/… name.
  • Avatars resolve from the commit author's email — a GitHub noreply address maps to that account's public avatar, any other address to Gravatar — falling back to a deterministic initials monogram; relative dates use Foundation's locale-aware formatting.

Install

Download FinderGit.dmg below, open it, and drag FinderGit to Applications. The app is signed with a Developer ID and notarized by Apple, so it opens with no Gatekeeper prompt. Existing users receive this update automatically.

Requirements

macOS 15 (Sequoia) or later. Universal binary — Apple Silicon and Intel.
