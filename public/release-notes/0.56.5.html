Release notes

FinderGit 0.56.5 — Open shows, it never acts

Highlights

  • Open shows, it never acts. In the Agents dashboard, opening a file shows Markdown, JSON, YAML and TOML in their usual apps and anything else in your plain-text editor. A file a repository names could otherwise reach an app that does more than show it: a terminal that can run it, Contacts or Calendar that import it, a browser that runs its scripts.

Under the hood

  • Only the names the dashboard is about (md, markdown, mdc, txt, json, jsonc, yaml, yml, toml) open in the app their type calls for; every other name opens in the plain-text editor, and neither may be an app that opens Unix executables. With neither left, the file is revealed in Finder.
  • The Open button's tooltip now reads "Open in an editor".
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.56.5.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
