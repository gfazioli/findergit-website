FinderGit 0.38.0

Release notes

FinderGit 0.38.0 — branches without a terminal, and a diff you can send out

Highlights

  • Create, rename, merge, rebase and delete branches without leaving the app. The switcher already listed branches and checked them out; this is the rest of it. New branch… sits at the top of the branch dropdown, with a starting point and a check out after creating toggle, and every row in the Branches tab carries the other four on a right-click. The name is checked as you type, so Create stays disabled and the field says "name" already exists rather than letting the command fail after you have committed to it.
  • A remote row offers Merge alone, on purpose: renaming or deleting origin/foo is a push to a remote somebody else owns. And the rebase confirmation says the part nothing on screen would suggest — Git checks out the branch being rebased, so you right-click a branch you are not standing on and end up standing on it.
  • Open a file's diff in Kaleidoscope. A button beside Refresh Diff sends the committed version and your working copy over, in a tab named for the file. Binary files arrive intact, which is rather the point of sending them out at all. A new file shows an empty left side instead of an error, and when Kaleidoscope is not installed the button is not drawn at all.
  • The action bar stops losing its buttons. On a narrow panel the actions that do not fit now move into an overflow menu instead of being clipped off the edge — and a control that is disabled says why when you hover it, rather than leaving you to work out which state of the repository is in the way.

Bug fixes

  • Two actions can no longer collide on one repository. Pressing Refresh during a fetch left that fetch running with nothing watching it, and its result would land on a panel that had moved on. It is one action at a time per repository now — and a refresh across many repositories reports which ones it could not reach, instead of letting you assume it managed them all. Three destructive confirmations also re-check whether the repository has become busy since the dialog opened.
  • Counts agree with their number in all four translations. Twenty-eight count-bearing strings were handing Italian, French, German and Spanish one English sentence to cover both one and many, so every one of them read as a plural at one; in French and Spanish the adjective was wrong besides.
  • Selecting the same path in another repository no longer shows the previous one's diff. A README, a lock file, anything two projects both have: the panel recognised the path and not the repository it belongs to.
  • A change of account reaches the Issues, Pull Requests and Overview panels, instead of leaving them showing what the previous one could see. A request already in flight when the credentials change can no longer land afterwards and overwrite what the new account fetched.
  • Branch and stash actions act on what the row was showing. A branch is resolved by the commit it carried and a stash by its own commit rather than its position in the list, so an entry that moved, or was applied or dropped elsewhere, is reported rather than acted on in place of the one you picked.

Under the hood

Two of these are nets rather than repairs, and both run on every build. One fails when a string carries a count and has no plural rule; the other fails when a FinderGitCore string would be looked up in the app's catalogue instead of the framework's own — a defect invisible by construction, because the translation really is present and the test run forces English.

Force-deleting a branch no longer goes through git branch -D. It compares the branch against the object ID the row was showing and refuses if it has moved, and it refuses outright while a rebase, a bisect or another worktree holds that branch — which the plumbing command, unlike the porcelain one, will not do on your behalf.

Kaleidoscope is found by bundle identifier, by the ksdiff symlink and by the conventional path, never by a PATH lookup: an app launched from the Finder inherits the system PATH, which does not include /usr/local/bin, so a lookup that works in every terminal you test it from fails in the shipped app.

The suite stands at 747 cases.

Install

Download the DMG below, drag FinderGit to Applications, and open it. The app is signed with an Apple Developer ID and notarized by Apple, so no Gatekeeper bypass is needed. Existing installs update themselves.

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
