FinderGit 0.43.0 — pull to refresh in the repository detail panel

Highlights

  • Pull to refresh in the repository detail panel. On macOS 27, pull the detail panel down to refresh the tab you are looking at, as the file browser and the repository lists already allow. It works on a short list, an empty result and a load error too, and the spinner lets go after at most two seconds while slower work carries on.
  • Each tab refreshes only what it shows. Overview reloads the forge details, counts, fork information and local worktrees. Unstage, Commits and Branches re-read local status, history or branch lists. Issues and Pull Requests skip the cache and refresh their badges and any expanded thread. Release reloads local tags and forge releases, and repeats the remote-tag check if you had already run it. Maintenance re-runs the disk-usage report, while the expensive history analyses stay opt-in. Trust re-scans the selected repository without changing its trust setting. Pulling never runs Fetch, Pull, Push or a cleanup.
  • Release's Refresh button matches the pull. Besides the forge releases, it now reloads the local tags and repeats a remote-tag check you had already run.

Under the hood

The detail panel keeps a single scroll view, so the pinned Issues, Pull Requests and Release headers are unchanged. A pull bumps a refresh token passed down the environment. Only the mounted tab reacts to it, including its empty and error states, and a tab opened afterwards does not replay an earlier pull. Each tab reports whether its own load is still running through a preference, which holds the spinner until the work ends or the two-second cap passes, and a refresh already in flight is never started a second time. On macOS 15 and 26 the Refresh buttons remain the way to refresh.

Install

  1. Download FinderGit-0.43.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
