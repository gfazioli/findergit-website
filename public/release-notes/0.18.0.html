FinderGit 0.18.0

Release notes

Highlights

  • Four new languages — FinderGit is now fully localized into Italian, French, German, and Spanish, alongside English: every view, menu, dialog, tooltip, and setting. It follows your Mac's system language automatically — nothing to configure.
  • Localized end to end — counts and labels inflect correctly in each language ("1 commit" vs "2 commits", the right way, everywhere), the update dialog and the macOS permission prompt follow along, and from this release the post-update "What's New" panel arrives in your language too.
  • Prefer English? Nothing changes unless your Mac's language is one of the new four.

Under the hood

  • Built on Apple String Catalogs: all languages ship inside the one universal binary and resolve at runtime from the system language — no separate downloads.
  • ~600 app strings plus the framework layer per language, with proper plural variations; git jargon (commit, push, fetch, stage…), brand names, and shell commands stay verbatim in every language by design.
  • A committed i18n toolchain (scripts/i18n/i18n.py) keeps future translation passes and per-release What's New localization reproducible, with automatic placeholder-parity checks.

Install

Download the DMG from findergit.app, or update in place: FinderGit → Check for Updates… — signed and notarized, no Gatekeeper hoops.

Requirements

  • macOS 15 or later — universal binary (Apple Silicon + Intel).
