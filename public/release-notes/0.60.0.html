FinderGit 0.60.0

Release notes

FinderGit 0.60.0 — starred repositories, anyone's public profile

Highlights

  • Your starred repositories in Clone Repositories. A switch at the top of the window picks My Repositories or Starred: the repositories you starred on GitHub, whoever owns them, newest star first, with a sort by the date you starred each one. FinderGit remembers the choice, and each list keeps its own sort. With a fine-grained token, add Starring: Read to see the list; without it, the list says which permission is missing.
  • Already on this Mac, at a glance. A repository you already have anywhere in your root folders shows a drive icon instead of a checkbox, and hovering it shows where it is. FinderGit matches the checkout's GitHub remote, so a folder you renamed or moved still counts. Not on This Mac in the Type menu hides the ones you have.
  • Open on GitHub from any row. The arrow at the end of each row opens the repository on GitHub; right-click for Open on GitHub and, on a repository you already have, Reveal in Finder.
  • Anyone's public GitHub profile in Account. The menu beside the title offers View Another Account…: type a username, @username, or paste a profile URL. You can Save the profiles you look at often, and Back to My Account returns to yours. Right-click a repository and choose View Owner's Profile to open its owner. Another person's profile is marked Public profile and shows only what GitHub makes public. Organizations aren't supported yet, and FinderGit says so.
  • Updates are checked more strictly. FinderGit now accepts an update list and release notes only when they are signed with its own key, and it verifies each download before opening it.

Bug fixes

  • The Overview could keep showing stale numbers while it was open: stars, issues, pull requests, sizes and security findings loaded in another window reached it only on the next refresh. They now reach the open Overview within a moment.

Under the hood

  • The starred list uses GitHub's /user/starred (REST) or gh api (GitHub CLI), up to 2,000 repositories, cached like the repository list. "On this Mac" resolves every root's remotes when the window opens and keeps them current across late scans, moves and Refresh.
  • A public profile is one GraphQL request. A rate limit or other GraphQL error is reported as such, never as "no such user", and the profile reloads when the token changes.
  • The Overview observes the size, trust, remote-counts and fork stores, and it rebuilds from the window whose summary it last showed.
  • The Sparkle feed must now carry a valid EdDSA signature (SURequireSignedFeed), each download is verified before extraction (SUVerifyUpdateBeforeExtraction), and the release-notes link carries its own signature.

Install

  1. Download FinderGit-0.60.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
