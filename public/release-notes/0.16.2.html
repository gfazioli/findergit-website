FinderGit 0.16.2 — Snappier and steadier

Highlights

  • ⚡ Lighter and more responsive — the Account dashboard no longer keeps FinderGit working in the background. The app stays snappy and checking for updates is fast again.

Bug fixes

  • 🐛 Fixed the Account dashboard quietly using CPU while open, which could make the whole app feel sluggish and slow down the update check.
  • 🔌 Sturdier Git and GitHub operations — a network call that can't reach a server now fails fast instead of lingering in the background.

Under the hood

  • The contribution heatmap resolves each cell's colour and tooltip once instead of recomputing on every frame, and the Stars-badge pulse is now finite rather than indefinite — together they stop a continuous SwiftUI/CoreAnimation redraw loop that pinned a CPU core.
  • The launch update check (Sparkle) runs once per process instead of re-firing for every new window/tab.
  • git/gh subprocesses now run with GIT_TERMINAL_PROMPT=0 + askpass guards and a timeout + cancellation kill, so they can't hang on a hidden credential prompt or a wedged network call; gh no longer blocks a cooperative-pool thread on waitUntilExit().

Install

Download the DMG below, drag FinderGit to your Applications folder, and launch it. Existing installs update automatically.

Requirements

  • macOS 15 (Sequoia) or later.
