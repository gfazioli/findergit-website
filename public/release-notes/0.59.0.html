FinderGit 0.59.0

Release notes

FinderGit 0.59.0 — Codex sessions, and sessions gone for good

Highlights

  • A Codex Sessions card in Agents. Codex saves a session for every conversation and for every codex exec and codex review a command or an agent runs, and they pile up in its list. The card shows them, read from Codex itself, each with its size on disk: the task threads every review runs in, together in one row, your conversations newest first, then the sessions from commands and the archived ones.
  • Archive or delete them through Codex. Select Commands ticks every session a command ran and leaves your conversations. Archive is Codex's own: the session leaves its list, and codex unarchive brings it back. Delete removes it for good. A session open in Codex or another program, or written to within the hour, is marked and left alone, and every session is checked again just before Codex acts on it.
  • Delete next to Remove in Background Sessions. Remove runs claude rm and keeps the conversation for claude --resume. Delete does the same and also moves the conversation to the Trash, where the Finder can put it back. It checks first that no program has the conversation open, and leaves the session alone when one does; a conversation opened while the session was being removed stays where it is.
  • Terms of Use and Privacy Policy are a click away, in the Help menu and the About FinderGit window.

Bug fixes

  • In Spanish, French and Dutch, the Remove and Delete buttons of Background Sessions and their confirmations read the same, though one keeps the conversation and the other does not. They now read differently in every language.
  • The help for Show author avatars said every author's picture came from their GitHub account. It now says what happens: GitHub only for a GitHub noreply commit email, Gravatar, which receives a hash of the address, for everyone else.

Under the hood

  • The Agents dashboard comes from AgentsKit 0.18.2. Codex sessions are archived and deleted through Codex's own app-server (thread/archive, thread/delete), never by moving its files, and only sessions with a valid id are sent. Claude Code conversations go to the Trash only after Claude Code's own listing and an open-file check both say nothing holds them.

Install

  1. Download FinderGit-0.59.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
