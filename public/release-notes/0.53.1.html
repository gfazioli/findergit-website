FinderGit 0.53.1

Release notes

FinderGit 0.53.1 — Sections you can see, and Agents finds more

Highlights

  • See what each section does. In the glancecard window the preview now draws a repository card too: pick Repository above it, or tick a section, and a sketch shows each section where glancecard puts it — Rhythm beside Code, Latest commits beside Releases, and the one left taking the full width when its neighbour goes. The first section is now called Summary: it is the panel under the card's title, not the header, which every card keeps.
  • A place's findings in one go. On Agents, a place's row in Launch Weight shows its warnings and suggestions while closed and, opened, hands every one of them to Claude Code or Codex in one session, writing only where that place's own files are.
  • Found where Claude Code looks. Skills are listed the way Claude Code lists them, so a large folder inside one skill can no longer hide the skills after it, and a skill one folder too deep shows as Ignored, with a suggestion. Each place's memory is found where Claude Code keeps it: a linked worktree reads its main checkout's, and a memory folder moved in the settings is followed.

Bug fixes

  • The workflow and the README lines in the glancecard window keep each line whole and scroll sideways: a long list of sections wrapped to the left margin and looked like broken YAML. What you copied was always right.
  • With no repository listed, the sections only a repository card draws are set aside, and the workflow no longer writes a sections line that changes nothing. Stars stays a choice, the one section the profile card draws.
  • Cards stay still as they open and close: their figures no longer count up from zero again, an open card no longer jumps on a refresh, and resizing the window keeps an open panel's figures at rest.

Under the hood

  • The repository sketch follows glancecard's own layout (its renderer's order, pairs and section heights) in the look picked, with shapes in place of the figures: the app draws no repository card of its own. It wears the Profile Card's frame and panels, and its two grids are drawn as one canvas each.
  • Which sections a setup can draw is one rule in the app's core, read by both the workflow and the checkboxes.
  • The Agents page comes from AgentsKit 0.9.4 → 0.9.9, shared with Lancetta.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.53.1.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
