FinderGit 0.61.0

Release notes

FinderGit 0.61.0 — pull a whole smart view at once

Highlights

  • Select several repositories in the repository list. ⌘-click, ⇧-click or Select All (⌘A) in All Repositories, Favorites, Recents, any smart view or host filter. The panel beside the list becomes the selection's summary: how many, how many are clean, dirty, ahead and behind, and Fetch, Pull and Push for the whole group. Right-click the selection for the same three, plus Reveal in Finder; the Repository menu's Selected Repos commands act on it too.
  • Pull All in Behind, Push All… in Ahead. A strip above the list says how many repositories are ready — 12 repositories ready to pull — and one click pulls every one of them, with the progress card showing each. Push All… asks before it pushes, like every bulk push.
  • Diverged repositories are left out, and the strip says so. A diverged repository sits in Behind and in Ahead, but a plain pull or push cannot settle it, and a merge or a rebase across a dozen repositories at once is not a decision one button should make. The strip counts them — 2 diverged, left out — and the Diverged view is where each one gets its choice.
  • After a bulk pull, the list keeps up. Repositories that caught up leave Behind, and leave the selection with it, so the next button acts only on what is still there.

Bug fixes

  • The repository list keeps keyboard focus from the first click on a row. Opening the detail panel used to rebuild the list without it, so the arrow keys needed a second click.

Under the hood

  • The table's selection is a set of URLs. One row shows the repository's detail panel as before; several show the summary, and a group selection is intersected with the visible rows whenever they change. Only a lone selection is recorded in Recents, so sweeping forty rows to pull them is not forty visits.
  • The table, the detail panel and its resize handle now live in one container (AnyLayout) instead of three branches, so the table is not rebuilt when the panel appears or the layout flips — which is what took its keyboard focus.
  • Pull All and Push All reuse the existing bulk runner: a few repositories at a time, repositories without an upstream skipped rather than failed, the push behind the same confirmation. Which rows they take is a pure function with tests that go red if diverged rows are included.
  • The Fetch / Pull / Push buttons of a multi-selection are one view, shared by the file browser and the repository list.

Install

  1. Download FinderGit-0.61.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
