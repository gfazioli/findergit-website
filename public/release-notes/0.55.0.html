FinderGit 0.55.0

Release notes

FinderGit 0.55.0 — Agents reads what Claude Code really loads

Highlights

  • More of what Claude Code loads. The rules of subfolders, which Claude Code reads when a session works there, are listed with the folder they belong to; your organization's managed rules and the instructions its policy carries are listed and counted in each launch they join. Rules are matched as Claude Code matches them, from the folders above a repository into the repositories below it, linked worktrees included.
  • More programs checked. Your organization's own hooks, status line and helpers, its policy helper, file suggestions, the subagents' status line, the background sessions' launcher and gcpAuthRefresh are checked too, and each finding lands in the file that names the program. MCP servers your organization keeps from starting are no longer flagged.
  • Storage, always there. The Storage card stays on Agents once it has looked, and says All clear when nothing can go.

Bug fixes

  • A rule behind a link Claude Code doesn't follow no longer vanishes from the list: it is listed as ignored, with a finding that says where the link leads.
  • An import out of a repository is worded by who reads the file: in a committed one, everyone who opens the repository is asked once; in one only you have, it is judged as your own sessions read it.
  • A file a CLAUDE.md imports no longer reads as uncommitted when git tracks it.
  • A session handed a rule or a CLAUDE.md of a folder above now starts in the folder that owns it.
  • One file linked into several repositories is no longer reported as duplicated paragraphs.
  • Nothing is ever offered to fix inside your organization's policy.

Under the hood

  • The Agents page comes from AgentsKit 0.13.1 → 0.15.0, shared with Lancetta, read against Claude Code 2.1.306.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.55.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
