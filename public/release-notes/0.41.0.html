FinderGit 0.41.0

Release notes

FinderGit 0.41.0 — zoom that reaches the whole window, and a sidebar that keeps its icons

Highlights

  • Zoom now reaches the whole window. View → Zoom In, Zoom Out and Actual Size (⌘+, ⌘− and ⌘0) used to change the file tree alone. They now scale the file browser, All Repositories, Favorites, Recents, the smart views, the filters and the Overview and Account dashboards: text, rows, cards and the contribution calendar together, while the sidebar and the toolbar stay put.
  • Familiar steps, from 75% to 300%. The same levels Safari uses. Settings → General offers them as a Zoom menu in place of the tree's text-size slider, and a tree you had set larger opens at the zoom that matches it. At either end of the range the menu item that would do nothing is disabled.

Bug fixes

  • Zoom Out and Actual Size work again. The rows already on screen ignored a zoom change until the folder was opened again, the top row most visibly, so after zooming in there was no way back short of leaving the folder. Every step now redraws what you are looking at, both ways, and rows get shorter again even in a folder or a list you opened while zoomed in.
  • A selected row in the sidebar keeps its icon. Overview, Account and Behind drew theirs in the same blue as the selection, so it vanished the moment you picked them. A selected row's icon turns white now, as in the Finder, and keeps its color while the window is in the background.
  • The contribution calendar on the Account no longer breaks the name of a month over two lines when only one of its weeks is in view.

Under the hood

The zoom is one observable model that every cell reads. A SwiftUI Table redraws a visible cell for what the cell reads, never for what its column closure captured, which is why the old @AppStorage font size left the rows on screen unchanged: four Zoom Outs moved the setting from 17 to 13 points and the tree stayed pixel for pixel the same.

Text styles do not scale on macOS by themselves, and scaling the picture draws text at actual size and enlarges the bitmap, visibly soft at 150%. So the zoom scales the fonts, at each text style's own size and weight, and the sizes laid out round them. At 100% everything renders exactly as before.

Two Table behaviours shaped the row heights. The table reads its minimum row height once, when it is created, so the zoomed minimum lives on each row's first cell. And a table created after its window is already on screen leaves a stale ideal-height constraint pair on its first-column cells, so its rows could grow but never get shorter than they were born; a small repair clears the duplicate on each zoom change.

The screenshot pipeline now refuses to shoot when FinderGit is not the frontmost app.

Install

  1. Download FinderGit-0.41.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
