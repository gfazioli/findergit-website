FinderGit 0.74.0

Release notes

FinderGit 0.74.0 — CI and security at a glance

Highlights

  • Actions and Security cards. A repository on GitHub has two new cards on its Overview. Actions reads the newest run of each workflow on the default branch: red when one fails, blue while one runs, green when every one passed. Security counts the open Dependabot, code scanning and secret scanning alerts in the color of the worst, and an exposed secret counts as the worst there is. Each card opens into its list, and every row opens on GitHub. When a card can't vouch for a green, it says so instead: Not all workflows checked, Not all alerts visible.
  • Checks and Dependabot columns in the file browser and the repository list: the mark GitHub shows beside the newest commit of the default branch, and the open Dependabot alerts in the color of the worst. Sort by either to bring the repositories that need you to the top. A Dependabot cell stays empty rather than showing 0, because GitHub answers zero both when there are none and when your account can't see them.
  • Two new cards on the Overview: Failing checks and Dependabot, each opening into the repositories it counts.
  • Optional token permissions. With a fine-grained Personal Access Token, add Actions, Dependabot alerts, Code scanning alerts and Secret scanning alerts (read) for the cards you want; a card whose permission is missing names it. With the GitHub CLI there is nothing to set up.

Bug fixes

  • The toolbar's Refresh re-reads the Issues, PRs and Stars counts a few repositories at a time, not every repository at once.
  • After you change your GitHub token, the Overview fills its GitHub figures again instead of staying blank.

Under the hood

  • The columns and the Overview cards cost one GraphQL request per repository (statusCheckRollup on the default branch's newest commit, vulnerabilityAlerts), in a query of its own beside the counts: gh api graphql exits non-zero when any single field errors, which would have emptied the counts with it.
  • The Checks column counts every check and commit status on that commit, a deploy preview's included, so it can be green where the Actions card has no runs.
  • The Security card asks for secret scanning alerts with hide_secret=true and never decodes a secret's value.

Install

  1. Download FinderGit-0.74.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
