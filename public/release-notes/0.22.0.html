Release notes

FinderGit 0.22.0 — See what you're behind on

Highlights

  • Incoming commits in the Commits tab. When a repository is behind its upstream, the Commits tab now opens with an "Incoming" section listing exactly the commits your next pull will bring in — each marked with a ↓, above your local history. So you see not just that you're behind, but what. It reads from what's already on disk, so nothing hits the network, and the section folds away the moment you pull.
  • "Last fetched" in the detail bar. Every repository's detail bar now shows when it was last fetched ("Last fetched 3m ago"), so the background auto-fetch finally has visible proof it's keeping your repos current.

Both are fully localized — Italian, French, German, and Spanish, following your macOS language.

Under the hood

  • Listing incoming commits is a local git log HEAD..@{upstream} — the objects are already present from the last fetch, so it adds no network round-trips.
  • Background auto-fetch is lighter: it refreshes each repo's branch and ahead/behind state with a plain status recompute instead of a full worktree refresh, so scheduled fetches stay quiet and cheap.

Install

  1. Download FinderGit-0.22.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — signed with Apple Developer ID and notarized by Apple

Requirements

macOS 15 Sequoia or later.
