FinderGit 0.56.6 — A ceiling on what Agents reads

Highlights

  • A ceiling on what Agents reads. The Agents dashboard runs a few commands to look at your repositories and your coding agents' sessions, and it kept everything one of them wrote until that command finished. A command that wrote without end could fill FinderGit's memory for up to thirty seconds. It is now stopped once it has written 64 MB, far more than any real answer, and of what it says went wrong only the last part is kept.

Under the hood

  • AgentsKit 0.15.5: the command runner stops stdout at 64 MiB (room for a whole repository's git ls-files -z) and reports the command as too long, which every caller already treats as no answer; stderr is read to its end and keeps its newest 64 KiB.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.56.6.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
