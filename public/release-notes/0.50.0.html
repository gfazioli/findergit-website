Release notes

FinderGit 0.50.0 — Agents, and dashboards that open in place

Highlights

  • A new Agents dashboard. It reads the files your coding agents load before your first prompt (Claude Code, Codex, Cursor, Copilot and Gemini CLI), in every repository, the folders above it and your home folder. It shows what each costs at launch, runs 20 checks that each say why they matter, lists files no agent uses (they can go to the Trash), and removes Claude Code's ended background sessions the way Claude Code documents.
  • Fixes it guides. Five kinds of finding have one right answer: the fix is shown in full before it is applied, and applied whole or not at all. The rest open in Claude Code (in plan mode) or Codex with the prompt already written. The button names the agent whose file it is.
  • Cleaning says what a folder really frees. Folders shared with other copies (pnpm stores, APFS clones) and folders committed to git are listed with a badge instead of being left out without a word. New Settings → Cleaning sets when a project folder counts as stale, the smallest folder listed, and whether shared or committed folders show.
  • Cards that open in place. On Agents, Cleaning, Overview and Account, a card opens into its panel right under its row. Account's contributions, top repositories and languages are cards now.
  • An About window that fits a 13-inch screen, in two columns, with a link to the Undolog Discord.

Bug fixes

  • Cleaning counted a folder whose files were hard-linked inside it as freeing nothing.
  • A folder hidden by a Cleaning setting never arrives ticked.

Under the hood

  • The Agents dashboard is built from AgentsKit 0.4.0, shared with Lancetta.
  • The release script refuses a screenshot the site still references but the release deletes.

Install

  1. Download FinderGit-0.50.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
