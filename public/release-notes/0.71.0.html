FinderGit 0.71.0

Release notes

FinderGit 0.71.0 — A status bar, and a filter that works in every folder

Highlights

  • The file list has a status bar, as in Finder. On the left, how many items the folder holds; with a filter on, how many it shows out of how many; with a selection, how many rows and the size of the selected files, then how many of the rows are repositories. On the right, the repositories' clean, dirty, ahead and behind counts (the same tallies the Repository List shows), the files with changes when you are inside a repository, and the space left on the disk. When the column is narrow the right side gives up its pieces first. View → Show Status Bar (⌘/) hides it.

Bug fixes

  • The filter works in a folder you have entered, and in a folder opened with its triangle. In both, the list kept every row while the field said what to look for. The filter now applies to the folder on screen and follows you into the folders you open; when nothing matches, the list says so and you stay in the folder, where before an empty result sent you back to the top. Inside a repository, Git Only still shows all of its files.
  • A file created or removed in a filtered folder appears or goes under the same filter, instead of bringing every row back.

Under the hood

  • The filter no longer works on copies of the tree. Each folder holds the rows the filter keeps, on the very object the table already shows, because the table keeps the row it has for a path and never read a copy's rows.
  • The free space is read off the main thread, and a slow volume's late answer can no longer overwrite the next folder's.

Install

  1. Download FinderGit-0.71.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
