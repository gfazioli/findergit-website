FinderGit 0.42.0

Release notes

FinderGit 0.42.0 — pull to refresh in every list, and action bars that stay in reach

Highlights

  • Pull to refresh in the file browser and every repository list. On macOS 27, pull the file browser, All Repositories, Favorites, Recents, a smart view or a filter down to refresh it, as the Overview and the Account already allow. It is the same Refresh as the toolbar button and ⌘R: the file tree, Git status and the cached repository details. It works on a folder with only a few rows and on a filtered list with nothing in it, and the spinner lets go of the table after at most two seconds while the work carries on. The sidebar stays navigation and has no pull.
  • The Issues and Pull Requests action bar stays in reach. The bar at the top of each tab is pinned while the list or an expanded thread scrolls underneath it, so New Issue / New Pull Request, Open on… and Refresh are there at the bottom of a long list too, as the tag controls already were in Release.

Under the hood

The repository tables take the system's native refresh control, attached to the table's own scroll view, with vertical elasticity allowed so a short or empty table can still be pulled; a scroll view that already carries a refresh controller is left alone. Only the content table takes it: a test mirrors the window, with a sidebar list and a detail table side by side, and checks the sidebar never does, including when the table is created after the window is already on screen.

The Issues and Pull Requests action bars are pinned section headers of the detail panel's scroll view, the same construction as the Release tab, over an opaque backing tinted like the tab so rows pass under the bar instead of showing through it.

Install

  1. Download FinderGit-0.42.0.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
