FinderGit 0.78.0

Release notes

FinderGit 0.78.0 — Favorites from anywhere, a color and an icon for each root folder, and menus in color

Highlights

  • Favorites from anywhere. A repository used to go into Favorites only from the repository list's right-click menu, and the empty Favorites list asked you to star one without saying where. Now the star at the top of a repository's details adds it, and so do Add to Favorites in the file browser's menu and Repository → Add to Favorites (⌘D). A star after the name marks a favorite in the file browser as it does in the list, and the empty list says where the star is.
  • A color and an icon for each root folder and group. Right-click a root folder or a group in the sidebar and choose Color and Icon…: one of 13 colors or the accent color, one of 47 icons or the folder's own, with a preview of the row. A group's icon is drawn filled, as its archive box is, and a root keeps its look when you move or rename it.
  • Context menus in color. Every item in the file browser's, the repository list's and the sidebar's menus now has its icon on a colored tile, the color saying what it does: blue opens, Pull is blue and Push green as Behind and Ahead are in the sidebar, staging is orange, yellow is Favorites, red throws away. The Git actions sit under their own heading.

Bug fixes

  • With several tabs open, a root folder or group added in one tab didn't show in the others, and a change made later in a tab opened earlier could put its older list back over it. Every tab now shares one set of root folders and groups.

Under the hood

  • The root folder store is now one for the app rather than one per window. Each window keeps its own selection and history, and follows a root's moves from the moment it opened.
  • Root folder styles are kept by path in an app-wide store, as the Favorites are; a group's style lives in the group, optional so the groups saved before decode unchanged, and decoded so that an unreadable value costs its look and never the groups.
  • A menu draws an SF Symbol in the text color whatever color the code asks for, so each icon is a small image drawn when the menu opens: the system colors follow the appearance, and the white glyph stays readable on a highlighted row, where a colored glyph vanished into the accent color.

Install

  1. Download FinderGit-0.78.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
