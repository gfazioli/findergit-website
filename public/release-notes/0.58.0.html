FinderGit 0.58.0 — back, forward, and the keyboard

Highlights

  • Settings moves like System Settings. Back and forward arrows sit at the top of the window with the name of the pane beside them, and every way of getting somewhere counts as a step: a row in the sidebar, About, a search result, a pane opened from the Agents dashboard.
  • One history for the main window, as in Finder. Back returns to the view you had open in the sidebar, or to the folder you came from; Forward retraces it. The arrows are in the toolbar beside the title, and in View → Back and View → Forward (⌘[ and ⌘]). The Release Notes window works the same way.
  • The four dashboards from the keyboard. Overview, Account, Cleaning and Agents are in the View menu, on ⌘1 to ⌘4.
  • Edit → Search (⌘F) puts the cursor in the file filter, or in the Settings search.
  • The menus show each shortcut with your keyboard's own keys: on an Italian keyboard, for example, Back reads ⌘ò.

Bug fixes

  • ⌘F, ⌘[ and ⌘] did nothing on macOS 27: they were attached to buttons, and only a menu item's shortcut reaches the keyboard there. They now live in the Edit and View menus.
  • Widening or narrowing the window no longer makes a repository Overview's panels land again and redraw their charts from empty.
  • The View menu no longer shows a double separator line now and then.

Under the hood

  • The main window's history is recorded from where the window is (the sidebar row, plus the folders entered inside a root folder), so every way of moving counts without each one having to report it. Going back onto another root rebuilds its tree and opens the folders on the way.
  • The test suite no longer writes repository-trust entries into your preferences: hosted test runs keep them in a throwaway store, the leftovers earlier runs wrote are dropped once at launch (only those entries), and the test script refuses a run that adds one. Closes #333.
  • The repository Overview's panels use one layout for both widths, so crossing the two-column breakpoint moves them instead of rebuilding them. Closes #334.

Install

  1. Download FinderGit-0.58.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
