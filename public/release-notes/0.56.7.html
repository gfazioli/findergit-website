FinderGit 0.56.7 — Fixes that stay inside the repository

Highlights

  • Fixes that stay inside the repository. The Agents dashboard can fix some of what it finds in your repositories by itself, such as keeping a personal file out of git or giving Gemini CLI a settings file. A repository can make its .gitignore, or its .gemini folder, a link to a file or a folder somewhere else on your Mac, as a project unpacked from someone else's archive could. Applying the fix then wrote to the place the link pointed to, outside the repository, and the change stayed there. Agents now looks for such a link and leaves that fix out, so a fix only ever writes inside the repository it is about.

Bug fixes

  • A damaged .git file stays small. Agents reads each repository's .git file to learn where its checkout lives, and it read that file whole: a damaged one that claimed to be gigabytes long, while taking no room on disk, filled memory just as fast. It now reads it the way it reads every other file, up to a few megabytes.

Under the hood

  • AgentsKit 0.15.6: the .gitignore and Gemini-settings fixes are refused when their target is a symbolic link (git itself refuses to read a .gitignore that is one), and .git gitfiles go through the scanner's size-bounded reader (4 MiB). The package now builds with Swift's strict memory safety (SE-0458), its unsafe calls marked, with no change at run time.
  • Translated into Italian, French, German and Spanish.

Install

  1. Download FinderGit-0.56.7.dmg
  2. Open the DMG and drag FinderGit into Applications
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
