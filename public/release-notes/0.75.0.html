FinderGit 0.75.0

Release notes

FinderGit 0.75.0 — A beam on the Actions card

Highlights

  • A beam on the Actions card. While the card shows a run in progress, a beam of light goes three times round it, as the repository opens or after a Refresh, then stops: it never turns for as long as a build takes. When a later Refresh finds that run finished, the beam goes round once more, green if every workflow passed, red if one failed; a cancelled run ends it without a lap. An answer older than two minutes starts nothing, and the beam stands still under Reduce Motion.
  • An About window shared with the other Undolog apps. Its new Open-Source Licenses link shows the license of the open-source code FinderGit includes.

Bug fixes

  • Sorting by Checks, in the file browser and in the repository list, now brings the failing repositories to the top, then the running ones, then those that passed, and the repositories with no checks last. They used to come first, so the failures never reached the top whichever way you sorted.
  • The About & Support window no longer opens over an app in full screen, where a second window can push the full-screen one out of its Space: it waits for the next launch.

Under the hood

  • The About page, its launch rule and the move-to-Applications prompt come from UndologUI 0.1.0, the UI package shared by the Undolog apps; the Agents dashboard moves to AgentsKit 0.20.0, built on the same package. The About window's support content is unchanged, so updating opens nothing new.
  • The beam moves only on a current answer: one past its two minutes, outdated by a Refresh or being read again moves nothing, and a failed refresh stops it. It is finite on purpose: a turning beam costs about a tenth of a core, and the card's symbols stay still so the window doesn't redraw while a run is queued. It is ported from ismnoiet/border-beam-ios under the MIT License.
  • The website's Actions and Security screenshots are shot against canned GitHub answers, never a real repository.

Install

  1. Download FinderGit-0.75.0.dmg
  2. Open the DMG and drag FinderGit into Applications (or open it from there, and it offers to move itself)
  3. Launch normally — the app is signed with an Apple Developer ID and notarized by Apple

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
