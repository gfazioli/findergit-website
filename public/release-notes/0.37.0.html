Release notes

FinderGit 0.37.0 — every issue and pull request says how old it is

Highlights

  • The Issues and Pull Requests lists now say when each one was opened, and by whom. A quiet line under the title carries the author and the age, so you can tell what is recent — and whose it is — without unfolding a single row.
  • A pull request also shows the two branches it would merge, on the same line: the branch being proposed, and the one it would go into. A long branch name is shortened in the middle rather than at the end, because the end of a branch name is usually the part that tells you what it is.

Under the hood

Nothing extra is fetched for any of it. The creation date, the author and, on a pull request, both branch names already arrive with the listing on every route FinderGit uses to reach a forge, and until now they were read only by the preview that opens when you click a row. A collapsed row was discarding what the listing had already paid for.

The line is one translated sentence per shape rather than a row of separate words, and both shapes put the author first — "gfazioli opened two days ago" rather than "opened two days ago by gfazioli". That is not a style preference: a single sentence labels an Issue in one row and a Pull Request in the next, and with the author as the subject the verb agrees with a person, so no language has to decide the gender of the thing that was opened. Where the forge names no author there is no verb at all, only the date. Branch names are shown verbatim and are never translated.

Install

Download the DMG below, drag FinderGit to Applications, and open it. The app is signed with an Apple Developer ID and notarized by Apple, so no Gatekeeper bypass is needed. Existing installs update themselves.

Requirements

macOS 15 or later. Universal binary (Apple Silicon and Intel).
